# Ant Design 复用验收

本次将主窗口控件、历史截图预览按钮、原图窗口按钮与错误提示、截图工具选项按钮、OCR/二维码操作按钮改为使用 antd。贴图右键菜单使用 Dropdown/Menu，透明度使用 Slider；菜单打开、定位、键盘导航和越界调整交由 antd 处理。

## 完成条件

- 主窗口：最小化、最大化/还原、关闭均可触发原有窗口操作；失败显示通知。
- 截图历史：缩略图进入视区后加载，点击后显示打开状态；失败通知和缩略图重试入口保留。原图窗口可缩放、适应、恢复原始大小、全屏、切换截图和关闭，加载时显示 Spin，操作失败显示可关闭的 Alert，切图失败可重试。
- 贴图：首次右键即可打开菜单，设置读取中禁用透明度和锁定操作；读取完成后透明度可在 20%～100% 之间调整，支持鼠标和键盘。锁定后菜单仍可打开并解锁；保存中、保存失败、重试保存及读取失败后重新读取均有入口或反馈。点击外部及 Escape 可关闭菜单，操作失败时保留错误反馈。菜单上的滚轮不会触发贴图缩放。
- OCR/二维码：重试、复制、关闭和链接操作保留原有回调；复制成功后的禁用状态、失败反馈保留。
- 工具选项：颜色选择、收藏与样式保存重试继续执行原有回调，忙碌状态不能重复提交对应动作。

此次替换不更改 IPC 和数据存储。贴图选项仍通过 update_pin_options 写入、get_pin_options 读取；应在关闭菜单后重新打开确认已保存值。历史及截图设置继续使用原有本地数据链路。

画布选区、缩放平移、窗口拖拽、画布内文字编辑器保留专用实现，其中原生 input/textarea 承担与截图像素和文字布局关联的编辑职责。

## 最短人工验收路径

1. 打开主窗口，操作窗口按钮，切换深浅色；进入截图历史，点击缩略图，在原图窗口缩放、切图、全屏和关闭。缩小窗口后确认工具图标仍然可见。
2. 发起截图，选择文字识别或二维码识别，检查复制、重试和关闭；打开颜色选择器并调整样式。
3. 将截图贴到桌面，右键打开菜单，调整透明度，锁定后再次右键解锁；关闭菜单再打开确认值保持。使用 Tab/方向键、Escape，并在贴图边缘打开菜单，检查焦点和菜单可见范围。
4. 若可制造读取或写入失败，确认错误可见，重试可恢复；在无截图可预览时确认原图窗口给出说明和重试入口。
