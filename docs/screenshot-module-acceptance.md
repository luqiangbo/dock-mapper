# 截图模块统一交互验收

## 默认值与生命周期

- 形状、直线、箭头、画笔：`#E03131`、6 px、手绘强度 2、实线、不透明，形状无填充。
- 文字：微软雅黑、24 px、红色；序号：默认屏幕直径 36 px、红底粗体白字、细白边，多位数字自动扩大圆形；高亮：24 px、红色、32% 不透明度。
- 开发服务启动或打包生成独立构建标识；热更新沿用。同一构建普通启动保留修改，新构建和重新安装恢复整个应用的设置。
- 主窗口初始化握手先提交配置及备份，再清理本应用偏好，最后激活快捷键、截图预热和依赖配置的功能。初始化失败显示错误及重试入口。
- 握手可能早于 Tauri `setup` 完成：后端异步等待所有原生状态注册后才执行重置；等待期间不持有初始化互斥锁，不阻塞窗口线程。就绪结果保留给迟到的请求，15 秒等待超时可重试，原生注册失败返回具体原因。
- 开发服务重新启动而原生进程仍运行时，主窗口触发程序重启，再应用新构建默认值，避免旧保存队列覆盖重置结果。
- 新增内部配置字段 `_defaults_build_id`，兼容旧配置；安装标识继续保留。保留截图历史、系统映射恢复备份和最后应用的系统映射，不修改 Windows 映射。
- 开机启动重置继续调用现有插件。插件删除失败时，仅在只读确认本应用的 Windows 启动注册项确实不存在后视为成功，兼容首次运行和重复重置；权限错误、启动项仍存在或无法确认时继续返回错误，不推进重置标识。
- 新增主窗口专用 `initialize_defaults(buildId, activate)` 握手和从窗口只读的 `application_ready` 查询；图片继续使用二进制通道，无新增依赖。

## 工具与反馈

- 描边色、填充色、背景色及文字色排在各工具设置前面。下拉框固定默认项置顶并标注，不随当前值变化重排。
- 形状填充可由透明改为实色，再在颜色弹层中清空为透明；“无填充”仍由现有字段表达。
- 二级菜单移除正常保存状态及占位；写入失败保留草稿、错误和重试。
- 高亮通过编辑器绘制；序号使用同一编辑器的组合对象，点击递增，可移动、删除和撤销；橡皮擦删除标注，组合序号整体删除，原始截图不受影响。
- 取色包含原图与可见标注，使用圆角方形面板、11×11 像素放大图、细网格、黑白中心框和短十字线。单击锁点后，鼠标移动不再改变采样点；用四向按钮或方向键每次移动 1 个原图像素，抵达图片边缘停止。按“复制颜色”或 C 复制，按“继续取色”或空格恢复跟随，Ctrl+C 仍复制整图，Esc 仍关闭截图。最近颜色通过原有配置事务保存。
- 单一 Excalidraw 历史驱动撤销/重做按钮及快捷键。初始双禁用、修改后可撤销、撤销后可重做，撤销后新修改清除重做分支。
- Ctrl+C 或 Enter 复制整张选区和标注，成功后关闭；文本输入框中 Ctrl+C 继续复制文本。失败保留编辑场景和错误，避免重复提交。
- Esc 一次取消截图；输入法组字时先结束组字。取消和新捕获令旧异步结果失效，旧任务不得重新显示浮层。
- 交互背景统一外部 55% 黑色遮罩、选区原始亮度、黑白双层边界；加载提示不叠加整区暗色背景。遮罩不参与导出。
- 取色锁点、辅助线、微调面板均为单次截图内的临时状态，不持久化、不进入导出、不移动系统鼠标。切走取色工具再进入会恢复跟随；准备失败提供重试，复制失败保留锁点并可重试。
- 序号按编辑器缩放换算原图尺寸，在不同 DPI 下维持默认 36 px 的屏幕大小；使用本机 Segoe UI Bold / Arial Bold 的专用字体别名，按字形可见范围居中，多位数字扩大直径，靠边放置时保留完整白边。字体加载失败显示错误，再次单击可重试；继续使用编辑器组合对象、统一历史和原有导出通道。

## 自动化证据边界

新增或扩展的测试覆盖：Rust 默认值、构建重置/普通启动/备份恢复/失败重试、IPC 权限，提前到达的初始化握手、就绪后重复握手、原生失败和等待超时后重试；前端偏好重置、默认项顺序、透明填充往返、工具路由、序号分组、快捷键与复制任务隔离，以及开发包/生产包历史桥接。

按仓库限制，本地只运行根目录 `pnpm typecheck` 及 `src-tauri` 的 `cargo test -- --skip model`。前端测试已编写，未运行前端测试套件，也未运行构建。

## 最短人工验收（未做真实交互验证）

1. 启动开发服务，检查红色、6 px、手绘、透明填充及文字/高亮/序号默认值；改色后热更新应保留，再启动开发服务应恢复整个应用默认值。普通重启同构建应保留设置，重新安装应重置，历史图片仍在。
2. 画矩形，选择填充颜色后清空，确认画面与菜单都回到透明；查看各工具颜色位置、默认项置顶、箭头图标及菜单无“已保存”占位。
3. 绘制高亮，连续点击序号，检查 1、9、10、99、100 的粗细、居中及边缘完整性；在不同 DPI 下比较屏幕大小。用选择工具移动序号，用橡皮擦删除序号并撤销恢复，确认复制/保存图片的数字与屏幕一致。
4. 取标注上的颜色，单击锁点后移动鼠标，确认采样不变；分别用按钮和方向键微调上下左右各 1 像素，检查坐标和颜色同步，四个边缘的按钮禁用且放大图中心不漂移。复制颜色后浮层保留，继续取色恢复跟随；模拟准备/剪贴板失败检查重试。辅助线、网格和面板不得出现在导出中。
5. 检查撤销/重做按钮由真实历史启用或禁用；验证拖动画笔、调整颜色、删除、撤销后新绘制及新截图；新截图不继承上一张历史。
6. Ctrl+C 复制后应关闭浮层，检查剪贴板包括所有标注；打开颜色菜单或编辑文字时按 Esc 应一次关闭，输入法组字时 Esc 先取消组字。模拟剪贴板失败应保留场景并可重试。
7. 明亮、深色及 125%/150%/200% DPI 下框选、松开、调整选区，观察亮度保持稳定；复制、保存和贴图的成品没有遮罩或边界。

当前未操作 Tauri 窗口，以上工具行为、程序重启和像素效果均未做真实交互验证。
