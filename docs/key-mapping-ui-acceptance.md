# 按键映射界面与右键策略验收

## 本轮行为

按键映射页沿用当前主题、字体及 antd 组件。顶部保留标题、运行状态、总开关和“添加规则”；刷新状态、清空规则收进“更多”。映射关系使用中性色键帽和方向箭头，编辑、删除使用带说明的图标按钮。写入只在对应控件显示加载，已有表格继续可见；后台轮询不显示加载动画。保存失败保留列表与编辑输入，开关成功不弹重复成功通知。

添加、编辑弹窗并排展示两个选择器，窄窗口上下排列。名称统一为“左 Ctrl”“右 Shift”“左 Win”“回车 Enter”等；支持中文、英文和内部键名搜索。两个选择器排除字母、主键盘数字及小键盘数字，目标额外提供“禁用按键”。旧规则及底层键码保留，历史字符值仅在编辑该规则时作为不可新选的回显项出现。

遗留系统映射使用可展开区域；正常为空时默认收起，读取失败、存在映射、格式异常或等待重启时展开。异常始终提供明确提示及重试入口。清理按钮仍需确认范围并请求 UAC。本轮未执行系统映射清理，配置格式及重置规则未改动。

七个窗口入口共用右键策略：只阻止浏览器 contextmenu 默认行为，不阻断事件传播，不拦截右键按下、抬起或键盘事件。监听幂等注册，并在热更新释放旧监听。已阅读本地 antd/rc-trigger 与 Excalidraw 对应处理器，确认自定义菜单未因 defaultPrevented 提前返回；这是代码证据，不能替代真实窗口验证。

## 最短人工路径

1. 打开按键映射页，分别使用明暗主题及窄窗口，检查标题、状态、规则关系、图标提示和弹窗排布；停留数秒，确认后台刷新不闪动。
2. 添加“左 Ctrl → 左 Win”，搜索 Ctrl、左 Ctrl、ControlLeft，确认名称清晰；确认字母与所有数字不出现在任一新选择器，只有目标可选“禁用按键”。不要在本轮验收中清理系统映射。
3. 使用已有字符规则进入编辑，确认原值可见、未丢失，其他新规则不能选该字符；模拟保存失败，确认弹窗、输入及旧列表仍在，再重试保存。
4. 检查总开关、单条开关、编辑、删除、更多中的刷新和清空确认。确认正常开关不反复弹成功通知；系统干净时遗留区收起，错误及待重启状态仍醒目。
5. 主窗口、截图、贴图、历史预览、挂件及按键展示窗口右键不出现浏览器菜单；贴图自定义菜单仍能复制、保存、锁定和关闭，截图右键领域操作正常。输入框 Ctrl+C、Ctrl+V 及截图快捷键不受影响。热更新后重复检查菜单无重复触发。

## 右 Alt 增补

- 新增独立 `AltRight`，界面显示“右 Alt”，源键和目标键均可选择并搜索；左 Alt 的旧 `Alt` 标识保持兼容。旧 `AltGr` 标识保留解析但继续排除可选项，不扩展其组合语义。
- 运行时使用右 Alt 的独立扩展扫描码，按下、重复和抬起共用现有状态机；遗留系统映射预览也能识别右 Alt。规则沿用现有配置保存和重读，失败反馈及重试保持原流程。
- 静态检查：`pnpm typecheck` 通过。自动化测试：`cargo test -- --skip model` 206 项通过、0 失败，3 项模型测试被筛除。新增测试覆盖选择入口、左右区分、配置序列化重读、源键/目标键/禁用与长按抬起；补充前端搜索测试但未运行前端测试套件。
