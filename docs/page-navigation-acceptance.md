# 页面状态保留与顺滑切换验收

## 改动入口与完成条件

主窗口侧边 Menu 控制 antd Tabs 内容区。Tabs 不销毁隐藏页，未访问页不提前挂载；菜单悬停和键盘聚焦仅预加载页面模块。首次进入允许显示模块及数据加载状态，再次进入保留页面实例、表单、筛选、分页、趋势范围、日志跟随选择及页面滚动位置。

每个页面通过 PageScope 接收活跃状态，截图历史和截图设置分别提供子页状态。下拉层挂在所属页面内；确认对话框在离页时关闭，添加映射对话框隐藏时保留输入。全局通知和用户已发起的操作不依赖页面可见性。

设置离页时 flush 防抖队列，不卸载保存控制器；成功回写缓存页，失败通过全局通知及原页面错误提示反馈。返回时有草稿、保存中或保存失败则保留编辑值，不以后台读取覆盖。读取有捕获代次检查，旧页面或旧修改之前的响应不能覆盖当前页面。

截图历史和按键映射返回时后台刷新，保留已加载内容；刷新失败显示错误和重试。日志轮询、挂件实时监听和图表订阅/绘制在隐藏时暂停，返回时恢复。全局系统采集、日志写入和已启动的软件更新任务继续执行。

## 状态和持久化边界

缓存页、表单草稿和滚动位置仅保存在当前主窗口内存中，关闭窗口后释放。已提交的设置和已有筛选偏好继续走原有持久化链路，未新增跨启动页面缓存。Rust 命令、IPC 和数据格式未改变。

首次加载失败仍有重试入口；后台刷新失败不清空已有列表。快速切换不取消已开始的写入，离页错误仍通过通知可见。

## 最短人工路径

1. 打开截图历史，修改筛选、排序和列数并滚动；进入挂件设置后返回，确认筛选与滚动位置保持，未出现整页加载。切换截图子页后确认历史筛选仍在。
2. 修改挂件预设名称、截图文件名前缀或按键展示字号，立即切页再返回；确认草稿/有效设置保持，待保存值最终显示成功。关闭并重新打开主窗口，确认已保存设置按原链路读取。
3. 制造设置写入失败后切页，确认通知可见，返回时草稿和失败反馈仍在；恢复可写条件后重试。
4. 离开历史页，完成一张新截图后返回，确认记录更新而筛选不变。读取失败时确认旧记录仍在，并可重试。
5. 仪表盘切换趋势范围、日志级别和跟随开关后离页；返回时状态保持，图表尺寸正确，日志恢复刷新。隐藏时检查不再发起日志读取和挂件布局刷新。
6. 在添加按键映射对话框输入但不提交，切页确认对话框隐藏；返回后确认输入保留。检查确认框、下拉层不会显示在其他页面上。
7. 快速连续切页、返回正在读取或正在保存的页面，确认旧读取不覆盖新修改；首次模块/数据加载失败后检查重试。

## 验证证据

新增 Vitest 状态测试覆盖离页 flush、重复 flush 不重复写入、保存失败后重试、读取期间修改使旧结果失效、页面隐藏/重新进入后的旧读取丢弃，以及隐藏日志页不发起读取。遵循仓库限制，本轮不运行前端测试套件。

交付检查仅运行根目录 `pnpm typecheck`（退出码 0）和 `src-tauri` 下 `cargo test -- --skip model`（退出码 0；158 项通过、0 失败、3 项被过滤）。新增前端状态测试未运行。未做真实 Tauri 交互验证，以上人工场景仍待确认，类型检查和 Rust 测试不证明页面交互通过。
