# 精简仪表盘与本机运行日志验收

## 当前界面与数据

- 仪表盘仅保留系统概览、上传／下载、CPU、内存、电池、趋势和运行日志。三个操作按钮、最近截图、状态异常横幅及运行状态详情已移除；过期采样通过占位和简短状态文字表达。
- 截图、历史、OCR、按键映射和更新继续从各自页面或已有快捷键进入。之前完成的 OCR 重试、历史方向键切图、更新进度及失败重试保留。
- 历史日期筛选改用 Ant Design 中文 `RangePicker`，支持单边日期及清除；起止日期当天全部记录包含在内。旧的日期字符串偏好继续可读，非法范围不保存，写入失败可以重试。直接依赖 dayjs 1.11.23，复用原有缓存版本。
- CPU 温度与 GPU 已整体移除：不再渲染、配置、查询或启动 PowerShell 采样进程。两种历史指标仅保留 Rust 反序列化兼容，规范化后从当前配置、预设和配对中移除；其他指标样式及顺序保留，若没有可用启用指标则恢复默认布局。
- 阈值配置、后台判断、弹窗、未读和已读机制已移除。旧的 localStorage 提醒记录没有被清除，也不作为运行日志展示。

## 日志行为

- 复用原 tracing 本机日志目录、按日文件和现有保留规则；不建立云端或第二套日志存储。运行日志读写命令仅授予主窗口，不接收文件路径。
- 界面显示最近最多 500 行，一次读取总量不超过 256 KiB；处理跨日文件、UTF-8 起始边界和未写完的末行，展示按时间排序。多行错误继承时间、级别和来源，读取截断时显示说明。
- 日志区域高 280px，工具栏仅提供“复制所有”“删除所有”两个按钮，以及“自动刷新”“自动滚动到末尾”两个独立开关，默认均开启。移除该工具栏的级别筛选、手动刷新及诊断导出；原全局设置中的诊断导出继续保留。
- 自动刷新开启且仪表盘可见时每两秒读取，关闭后取消后续轮询；已开始的读取允许完成。隐藏或离页时停止并使旧请求失效，返回时读取一次，关闭自动刷新时不会重新开启轮询。失败保留内容并提供重试读取。
- 自动滚动关闭时尽量保留当前可见行；开关开启立即移到末尾，新日志继续跟随。滚动位置不会隐式改写开关。两个开关只保留在当前页面实例中，不新增跨启动持久化。
- 复制所有读取本应用全部已保存日志，按文件日期顺序并继续脱敏，不受列表 500 行/256 KiB 限制。先等待前端待写队列完成，复用原生文本剪贴板；空记录、复制成功及失败均有反馈。
- 删除所有使用 antd 确认提示，仅清空本应用日志文件内容，不删除其他文件；保留 Windows 上已经打开的追加写句柄，新记录正常追加。删除期间停止读取，成功清空缓存，失败通知并重新读取；旧读取不得恢复已删除内容。后台继续产生日志时，清空后可以重新出现新记录。
- 日志记录重要操作、失败和恢复。前端操作只记录固定操作名和截断后的错误摘要，不记录命令参数和返回内容；截图输出、OCR 结果状态和采样可用性由 Rust 记录，不写入图片、OCR 文本或实际按键。更新只在阶段变化时记录，不逐下载块刷屏；读取及归档重复错误在状态变化或恢复时记录。
- 前端日志消息限制为 2 KiB，处理控制字符和空消息，并对含引号、字段前缀或 UNC 的完整 Windows 路径进行脱敏。前后端共用同一日志写入器；前端 IPC 使用可返回错误的写入路径，避免将异步排队误认为成功写盘。
- 写入失败保留最多 100 条待写记录并显示错误、待写数量和重试入口；队列满时明确说明新记录未保存。退出进程前仍未写入的内存队列不能跨进程恢复；已成功写入的日志重启后继续可读。日志故障不递归记录自身。
- 系统采样统计继续保留次数和耗时，温度／GPU 统计及专用测量脚本已移除。`sampling-baseline.json` 仅作为历史证据。

## 验证与人工路径

- 新增前端测试覆盖中文日期恢复、单边和清除、日志写入失败重试与队列上限、轮询停止／恢复、不重叠、旧结果隔离、刷新失败保留内容、日志筛选与滚动跟随判断。按仓库规则本轮不运行 Vitest，交由现有 CI 执行。
- Rust 快速测试覆盖旧指标和预设迁移、配对清理、默认保护、日志范围上限、按日读取、UTF-8／半行、多行错误与时间排序、脱敏、写入后重新读取、主窗口权限及命令注册。
- 交付检查仅运行 `pnpm typecheck` 和 `src-tauri` 下的 `cargo test -- --skip model`，不运行全量构建或模型测试。
- 2026-10-18 日志工具栏交付检查：`pnpm typecheck` 通过；Rust 实测结果：178 项通过，0 项失败，3 项模型测试被过滤。新增 Rust 测试覆盖全量复制不受 500 行限制及脱敏、清空后旧句柄继续追加、不影响其他文件、失败目录和主窗口权限。前端自动刷新及旧读取隔离测试已补充，尚未实际执行。
- 未做真实 Tauri 窗口交互验证。包含新命令与权限的原生程序才可用于验收，不能只用前端热更新搭配旧可执行文件。

最短人工路径：打开历史页 → 使用中文日期范围、单边范围和清除 → 切页重开确认偏好；打开仪表盘 → 关闭自动刷新并产生新日志，确认列表不变化 → 开启后更新；关闭自动滚动并向上阅读，确认刷新保留位置 → 开启后立即到底。复制所有并检查早于最近 500 行的记录；删除所有时先取消，再确认清空，产生新日志并重开应用确认正常追加。另模拟读取、剪贴板、日志写入和清空失败，检查提示、待写数量和重试。

旧配置验收：使用包含温度／GPU 及相互配对的旧布局、预设重新读取 → 确认只有支持的五种指标、配对已清理、其他样式不变；只启用旧指标的配置恢复可用默认布局。确认任务管理器中不再因这两项功能周期性启动 PowerShell。
