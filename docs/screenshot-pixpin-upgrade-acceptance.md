# 截图交互修复验收

## 当前交付边界

已移除长截图、局部放大标注、聚光灯、线段工具及贴图缩略模式。取色像素放大镜、贴图普通缩放和历史列表缩略图保留；不删除用户历史 PNG 或贴图。

已实现但未做真实交互验证。以下是人工验收步骤，不代表端到端测试已经通过。

## 取景框移动与标注

1. 框选后按 V，在无标注的空白处左键拖动，取景框应移动并截取新位置内容；按住空格可从任意工具临时移动，松开后恢复原工具。
2. 小于等于 3 像素的位移保持为单击。拖动后不能触发双击输出；初次候选双击仍只复制一次。
3. 拖动途中按 Esc、切换窗口失焦或取消指针，取景框应还原，截图继续编辑。
4. 添加文字、箭头、序号、马赛克，移动取景框使标注移出，再移回。标注应固定在原屏幕位置，移出只裁切显示；撤销、重做记录继续有效。
5. 命中标注时优先编辑对象；已选中对象的缩放和旋转手柄可继续使用。文字输入、输入法组合和弹层内空格不能触发取景框移动。
6. 在 100%、150%、200% DPI 和多屏环境核对边界、尺寸及一个物理像素的方向键调整；Shift+方向键收缩，Ctrl+方向键扩展。
7. 拖动时只预览，不应持续产生历史记录或配置写入。松开后核对工具栏位置、尺寸面板及实际输出一致。

## 工具入口与设置

1. 工具栏、更多菜单及工具设置中不再出现已移除功能；旧配置中的线段、聚光灯和局部放大被过滤，其余工具排列和可见性保留。
2. 更多入口始终为三个点。选择次级工具后入口和对应菜单项高亮，不增加额外一级工具按钮。
3. 截图浮层不再提供调整工具与输出入口及弹窗。打开主窗口「截图 → 设置」调整常用工具、操作和输出设置；保存失败应显示未保存，重试后重新打开核对。
4. 截图浮层、工具提示和取色面板不展示快捷键文字；现有快捷键仍可用，主窗口用于配置系统快捷键的表单保留。
5. 在画布上对箭头、画笔、高亮、文字、序号滚动鼠标，尺寸立即变化；选择已有对象后也能调整。停止约 250 毫秒后保存，7 px 不应跳回 6 px，重开截图核对保存结果。
6. 模糊马赛克滚轮改变模糊强度，像素马赛克改变颗粒；Ctrl+滚轮改变透明度。面板和输入框内滚轮不调整画布工具，输入法组字不受干扰。
7. 已生成的历史 PNG 和贴图仍可打开；Shift+双击贴图无动作且不能关闭贴图。

## 贴图与恢复

1. 轻点贴图不启动原生拖动，超过阈值后移动；普通双击关闭。分别检查慢速拖动、快速拖动后再次双击，以及右键菜单打开后的拖动。
2. OCR 选字优先，Alt+拖动强制移动。滚轮缩放、Ctrl+滚轮透明度、中键重置仍可用；锁定后不能移动或改变尺寸。
3. 拖动、缩放、复制、保存失败时提示不遮住整张图片，仍能查看和继续操作；按提示重试。只有图片无法加载才显示加载失败界面。
4. 连续调透明度时界面立即变化，停止约 250 毫秒后合并写盘；未完成前不能显示已保存。模拟目录不可写后重试，应保存最新值。
5. 修改透明度后立即关闭，恢复最近关闭贴图检查最终透明度；正常退出再启动，核对位置、尺寸、透明度和锁定状态。
6. 准备多张未关闭贴图，损坏中间一张 PNG 后重启。后续有效贴图应继续恢复，主窗口汇总失败记录；失败记录保留供下次重试，不留下本次失败创建的窗口。
7. 重复点击复制、保存或恢复，不产生并行重复操作。屏幕布局变化后窗口回到可见范围。
8. OCR 在不同缩放下文字框跟随图像，选择文字不截断；验证加载、无文字、失败、重试及 Shift+C 全文复制。

## 输出与错误结果

1. 复制、保存、贴图及历史使用相同装饰合成结果；验证圆角、边框、阴影、透明通道及鼠标热点。
2. 输出成功但历史写入失败时，明确提示操作已完成但历史未保存；不报告复制或保存失败，不诱导重复输出。
3. 文件保存对话框取消后可继续编辑，不创建该次输出历史。

## 存储与验证证据

- 设置使用原子 JSON，贴图使用 PNG 与原子 manifest；不将图片塞入配置 JSON，不增加云端服务或遥测。
- 透明度先进入 Rust 运行状态，再合并持久化；关闭和退出刷新待保存状态。写盘失败保留未保存提示和重试草稿。
- 自动化行为测试包含旧配置过滤、拖动提交/取消/边界、滚轮连续调整与重读保持、输出成功与历史失败分离、单张恢复失败后继续处理。

## 序号点击与样式精简（2026-10-22）

1. 截图框选一个不在屏幕原点的区域，选择序号。移动鼠标可看到下一编号预览，单击后徽标中心应与点击位置一致，并显示短暂的放置反馈；边缘点击仅裁切徽标，不把徽标移向内部。
2. 拖动超过 3 个逻辑像素（包括拖远再返回）不添加序号，也不产生箭头；同处快速双击只放置一个序号，不触发输出。失焦、取消指针及重新截图后，不得落入旧的异步放置结果。
3. 浮动选项仅保留风格、配色、大小三个 Ant Design Select。风格为平面、立体、像素；马卡龙默认逐个轮换，也可固定粉、绿、蓝、紫、黄、橙。大小改变和多位序号都保持点击中心，多位序号缩字而不扩大徽标。
4. 起始值、数字／字母／罗马格式、删除后递补位于主窗口「截图 → 设置 → 序号默认行为」，不占用浮动工具菜单。
5. 已选序号切换风格或配色后保持编号和位置；立体阴影应在底部，像素风的填充区域应能正常选中移动。测试序号编辑、橡皮擦、删除后递补、撤销重做，再复制／保存／贴图核对输出。
6. 重开截图核对风格、配色和大小保持；打开过主设置页后再调整序号，再保存其他设置，不能将序号风格覆盖为旧值。保存失败应提示并可重试，字体或放置失败允许再次单击重试。
7. 最短人工路径：非原点框选 → 序号单击两次 → 拖动一次 → 切换三个风格和配色 → 选中移动 → 撤销重做 → 复制粘贴 → 重开核对。人工覆盖多屏及 100%／150%／200% DPI。

本轮补充前端测试：非零选区原点和 DPI 坐标、拖动阈值、边缘居中、多位大小、马卡龙轮换、像素形状命中、风格部件顺序和兼容删除。前端行为测试按仓库限制未执行；已实现但未做真实交互验证。Rust 测试包含旧配置默认值、非法样式回退和样式序列化往返。
