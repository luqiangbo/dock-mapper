# 设置保留、恢复默认与全局字体验收

## 实现范围

- 安装器不再生成 `settings-reset.token`；旧标记被忽略。构建标识只用于启动握手和运行版本保护，安装、升级和开发服务器重启不会主动恢复配置或关闭开机启动。
- 继续使用原应用标识与 AppData 数据目录、原子 JSON 配置和备份。此前已被旧版本覆盖的配置无法保证恢复。
- 通用设置新增“恢复默认设置”。确认后恢复应用配置、运行时映射、快捷键、外观、导航、翻译服务配置及凭据，关闭开机启动并重启。
- 截图历史、收藏、日志、统计归档和遗留系统键盘映射恢复资料保留；不改写 Windows 系统键盘映射。截图历史现有的 30 天／100 张保留策略仍适用。
- 显式重置代次持久化，下一次启动才按白名单清除前端偏好；未完成的前端清理可重试。重置成功后拒绝旧窗口继续修改配置，管理员映射操作进行中拒绝重置。
- 重置写入失败恢复开机启动状态并报告错误；重启失败时保留“重试重启”入口，重试不再执行重置。
- 开机启动写入也经过后端配置事务锁，主窗口不再持有插件的直接启用／禁用权限，防止重置前排队的旧请求重新开启启动项。
- 通用设置新增本机字体选择、搜索、预览、刷新和恢复默认。DirectWrite 按家族枚举本机字体，优先显示中文家族名；配置由 Rust 持久化，前端缓存服务于首屏，窗口事件用于同步，重新聚焦时校准后端状态。
- 界面字体覆盖主窗口、截图工具栏、贴图菜单、历史预览、挂件、按键展示；截图标注和日志等宽字体单独保留。字体变化触发挂件重新测量，截图工具栏沿用既有 ResizeObserver。
- 字体读取和枚举失败有重试反馈，保存失败不替换持久化配置。未安装字体使用系统回退并显示提示。
- Windows 字体清晰度仍由 WebView2 与系统渲染决定，未新增不适用于 Windows 的“强制平滑”开关，也未修改系统 ClearType 设置。

- Tauri Rust 2.12.7、JS API／CLI 2.12.5；插件前后端配套升级，并更新 workspace 中原先固定到 API 2.11.1 的 override。
- Excalidraw 仍为 0.18.1。其固定的 Tabs 1.0.2 不声明 React 19 支持，针对该父依赖覆盖为 Tabs 1.2.1；不放宽 peer 校验。保留原字体、画布缓存边距与历史桥接加载器及对应测试。
- sysinfo 0.40.4：适配 System 初始化、启动时间的 Result，以及全局 CPU 使用率接口。失败传播到既有启动／系统映射错误反馈。
- windows 0.62.2、rfd 0.18.0 及其余直接 Rust 依赖更新至本次查询到的最新稳定版，锁文件同步。
- PaddleOCR 0.2.8 已在上游补足未启用加速器时的条件编译回退；解除本地 patch，保留 vendor 目录作为历史参考。ONNX Runtime 随依赖更新至 ort rc.15，仍使用上游必需的预发布运行库；不额外启用 GPU，不在常规验证中初始化模型。
- Node、pnpm、Rust 工具未安装或升级。未增加云服务、遥测或字体下载。
- `pnpm peers check` 无 peer 冲突。Excalidraw 的 `png-chunks-encode` 仍间接依赖已标记废弃的 `sliced@1.0.1`，本次没有替换其 PNG 元数据实现。

6. 检查字体枚举失败／空结果／刷新重试，以及已保存字体被卸载后的回退提示。模拟保存失败，确认读回仍是最近成功字体。
7. Windows 100%、150%、200% 缩放、浅深主题与窄窗口下，检查中文、英文和数字无裁切，菜单可操作、挂件宽度重新适配。截图标注字体和截图输出内容不应随界面字体变化。
8. 升级后的原生行为另测：文件选择和保存、剪贴板、系统采集、热键、托盘、软件更新及一次实际 OCR。OCR 模型测试保持 `#[ignore]`，不纳入常规自动化运行。

## 自动化证据边界

- `pnpm typecheck`：仅证明 TypeScript 类型。
- `pnpm test`：完整前端行为套件；重置组件测试检查交给 Ant Design 的内容／回调和 IPC 边界，不证明 Portal 的真实呈现。
- `cargo test -- --skip model`：核心逻辑、配置持久化／故障、重置写入保护、字体验证和真实本机字体枚举；重置测试替代开机启动外部调用，不修改本机启动项。
- 版本配套检查、工作流命令语法解析及发布脚本测试不等于安装包／远端发布成功。
- 未做真实 Tauri 交互验证，未验证完整 CI；生产构建、安装包、模型推理和 Windows 缩放视觉效果仍需以上人工路径验收。
