# Windows 桌面冒烟测试

此清单用于发布候选版本的手动桌面验收。日常修改仍只运行快速类型检查和跳过模型的 Rust 测试。

## WebDriver 准备

1. 使用与系统 Edge/WebView2 匹配的 `msedgedriver.exe`。
2. 确认本机已经安装 `tauri-driver`；缺少时先报告，不由测试脚本修改 PATH 或自动安装。
3. 构建发布候选程序后，通过 `tauri-driver --native-driver <msedgedriver.exe>` 启动驱动。
4. WebDriver 会话的应用路径指向本次构建的 `dock-mapper.exe`，不得复用已安装版本。

## 场景

- 主窗口：启动后能够读取 Scancode Map 状态；隐藏再从托盘恢复时状态不丢失。
- 截图：点击“开始截图”，窗口悬停边框出现；自由拖动仍优先创建手动选区。
- 标注：依次创建矩形、箭头、画笔、马赛克、文字和编号，重新选中并移动；撤销和重做顺序一致。
- 输出：复制和保存成功；取消保存时编辑器恢复且不出现未处理 Promise。
- 贴图：从历史连续贴出至少 5 张图片，窗口在鼠标所在显示器自动错位且同时存在；每张均可独立移动、缩放、锁定、复制、保存和关闭，关闭任意一张不影响其他贴图。
- 快捷键：`Ctrl+3` 从最小化和托盘状态恢复主窗口并进入截图历史；`Ctrl+Alt+P` 可显隐最近贴图，关闭最近贴图后自动操作上一张。
- OCR：块级结果可逐项复制，悬停结果时原选区出现对应定位框。
- 历史：复制、保存和贴图成功后各生成一条记录；取消保存不生成记录；页面不存在批量清理入口，收藏记录不受 100 条/30 天自动清理影响。
- 历史存储：新记录只写入最终 PNG 和清单，不生成原图或标注场景文件。
- Explorer 恢复：重启 Explorer 后任务栏挂件重新嵌入，采样继续更新。

连续执行 20 次截图与取消，确认没有卡在“正在截图”状态，任务管理器中的内存占用不持续单调增长；诊断日志中的最近截图 P95 与修改前同机基线相比不得退化超过 10%。

失败时导出诊断信息，并记录显示器数量、DPI、HDR 状态和 WebView2 版本；不要附带截图内容或 OCR 文本。

## DirectML 评估门槛

当前发布版继续使用 ONNX CPU。DirectML 只在独立实验分支启用，并分别测试 Intel 核显、AMD 显卡和 NVIDIA 显卡：

- 比较冷启动、预热后推理耗时、峰值内存和安装包增量。
- 初始化或推理失败必须自动回退 CPU，配置中不增加引擎选择项。
- 只有三类常见设备均能稳定完成模型测试且实际延迟明显降低，才允许进入正式依赖。
- DirectML、录屏和 GIF 不得复用静态截图的发布路径，也不得进入日常模型测试。
