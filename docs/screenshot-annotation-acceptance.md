# 截图标注样式与安装默认值验收

## 已实现行为

1. 绘图 API 就绪及新捕获初始化完成后重新同步面板样式，默认红色 `#e03131`、3px、明显手绘（粗糙度 2），避免面板红色但首笔仍为编辑器默认黑色。
2. 颜色弹层的卸载回调只在真正卸载时执行；颜色预览引发的重渲染不再关闭弹层状态。固定保存反馈区域宽度，避免状态文字改变时移动二级菜单。最终颜色提交继续持久化，保存失败保留重试反馈。
3. 对固定版本 Excalidraw 的本机绘图边界做集中适配：线段/箭头缓存边距随线宽扩展；规整/手绘只保留两档，端点缩减为无、箭头、实心三角、实心圆、横杠，端点选择器扩大以完整显示名称。
4. 系统字体目录包含常用中英文字体。在「截图 → 截图设置 → 截图常用字体」选择 1～10 个，默认微软雅黑、宋体、黑体、楷体、Arial、Segoe UI、Times New Roman、Consolas。字体选择写入原有 JSON 配置事务，已预热截图窗口也同步常用列表。只使用本机字体，不下载字体；未安装的字体由系统/原有字体回退机制显示。
5. 无填充使用斜线空色块，显示与提示均为无填充。关闭已有形状填充会真正清除背景；再次选择填充类型恢复选定颜色。
6. 每次安装成功时生成新的安装标记，同版本重装也会更换。首次启动重置应用设置、配置备份、开机启动及前端主题/导航/侧栏/历史筛选偏好。普通启动保持本次安装后修改的设置。截图历史文件和恢复 Windows 键盘映射所需的系统备份保留。未主动运行安装器，不改动当前机器上的用户配置。

## 实现边界

新增配置字段为截图常用字体列表、工具字体标识和内部安装标识，沿用既有配置命令和事务，不增加 IPC 命令或云端依赖。安装标记未变化时继续正常读写设置。

字体注册和端点缓存边距由构建适配器集中处理，针对锁定的 Excalidraw 0.18.1 同时匹配开发及生产文件。关键边界不匹配时停止打包并报错，避免依赖升级后静默失效。该适配器不依赖 TypeScript 编译器的内部 API。

## 最短人工路径

1. 安装新包并启动，截图画线、箭头和矩形：面板与首笔均为红色，默认有明显手绘效果；切换规整/手绘比较结果。
2. 连续拖动颜色选择器并点击快捷色，确认二级工具栏和弹层不闪动、不意外关闭；换一张截图确认已提交颜色保持。
3. 将线宽切至 12px，分别选择箭头、实心三角和实心圆端点，在线宽变化后检查两个端点完整；复制和保存后对比导出 PNG。位于截图物理边界外的内容仍按截图范围裁切。
4. 矩形默认检查空心斜线色块，选择填充色再切无填充，确认实际画面清空背景。
5. 配置常用字体，确认最多 10 项、空列表有反馈。选择微软雅黑、宋体、Arial、Consolas 输入「截图中文 ABC 123」，对比实际字形、编辑框和导出 PNG；重新打开截图确认字体选择保持。
6. 修改设置后普通重启，确认设置保持；用同版本安装器重装再启动，确认默认项恢复，历史截图及系统映射恢复备份仍在。
