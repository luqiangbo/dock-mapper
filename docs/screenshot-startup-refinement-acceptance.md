# 截图与启动体验验收（2026-10-30）

本轮序号规则取代之前的立体、像素和轮换配色验收。序号已做浏览器交互验证，主窗口隐藏与取帧已做开发版原生核对，具体范围见末节；其余场景未做真实交互验证。安装版冷启动的原始耗时基线尚未复测，也未取得本轮 CI 安装产物。

## 最短人工路径

1. 主窗口可见时，从按钮、托盘、快捷键分别截图。截图背景不含主窗口；完成、取消后主窗口保持隐藏，托盘仍能打开。延时截图、预设区域和快速 OCR 同样检查。捕获失败应重新显示主窗口并报告原因，允许再次截图。
2. 非原点框选，选择序号，依次放置 1、2、3。仅显示平面圆形，浮层只提供颜色与大小；默认红底白字、28px。调整已选序号、移动、删除、撤销、重做，复制后核对预览与结果一致。旧样式转为平面后启用橡皮擦，未擦除的序号不能消失。
3. 在 100%、150%、200% DPI 以及负坐标副屏核对点击中心与多位数字。改变显示器分辨率或位置后截图，确认使用同一显示器浮层且选区坐标正确。
4. 打开截图历史，图片占据卡片。悬停、Tab 聚焦时顶部出现时间与尺寸，底部出现操作，图片轻微缩放；打开删除确认或等待操作时浮层保持可见。验证复制、收藏、贴图、删除、筛选为空和缩略图失败重试。系统开启减少动态效果时不缩放。
5. 挂件恢复默认布局后，字号为 12px、图标为 14px。设置预览与实际挂件一致；自定义大小保存、重开后保持。不同任务栏空间下不应出现图标占位宽度与实际宽度不一致。
6. 映射规则保持现状：应用运行时有效，关闭到托盘继续，彻底退出停止。本轮未新增退出策略或系统级映射。

## 序号不显示与截图旧帧修复

- 已在真实 Chromium 页面复现：非原点框选、150% DPI、选择序号后单击，场景中没有序号。点击事件正常、字体已加载；根因是展开浏览器 DOMRect 时丢失其继承属性，转换坐标变成 NaN，点击被误判为选区外。现改为显式读取矩形坐标，并补充继承属性回归用例。
- 同一浏览器流程修复后能连续放置 1、2；已检查可见画面和 PNG 导出，两处徽标采样均为预期红色 `[224,49,49,255]`。使用模拟截图 IPC 与实际编辑器，不代表原生 Tauri 截图、剪贴板及贴图端到端通过。
- 原生捕获现在在后台确认主窗口隐藏、等待桌面合成，再记录高精度时钟。DXGI 的桌面帧必须不早于该时刻；旧缓存帧及只有鼠标变化的帧改走即时 GDI 捕获，保留预热设备。新增帧时间判断的 Rust 回归用例。
- 原生核对发现，仅窗口可见性变为隐藏并调用 DwmFlush，GDI 仍可能捕获到主窗口隐藏动画中的表面。现仅在截图期间关闭自身主窗口的 DWM 动画，捕获结束恢复；GDI 的未初始化 alpha 统一设为不透明，避免桌面部分区域变透明。
- 已在本机开发版、3840×2160、150% DPI 下，通过真实全局截图快捷键核对：可见主窗口背后放置绿色临时窗口，截图时主体隐藏，冻结画面保留绿色背景，未包含主体；已检查实际屏幕画面。取样避开截图放大镜并考虑选区外遮罩；Esc 取消后主体与浮层均保持隐藏。此项不等于安装版、全部入口或完整编辑流程通过。
- 剩余最短验收：显示主窗口 → 点击截图 → 核对冻结画面中没有主窗口 → 非原点框选 → 放置 1、2 → 复制并粘贴核对 → 取消或完成后保持主窗口隐藏。按钮、托盘、延时、OCR、多屏及安装版仍需真实交互验证。
