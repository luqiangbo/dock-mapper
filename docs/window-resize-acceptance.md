# 主窗口最大化、还原优化验收记录

记录日期：2026-11-01。以下原生交互证据来自本机开发版，安装版 CI 产物尚未复测。

## 实现范围

- 保留 Windows 原生最大化、还原和自定义标题栏。仅主窗口取消 Mica，页面使用随主题变化的实色背景；截图、贴图和挂件窗口不调整。
- 主窗口通过现有窗口及 WebView API 同步底色。快速切换主题时串行写入，跟随系统时不强制锁定主题。同步失败显示通知；相关权限仅授予主窗口。
- 独立尺寸活动协调器在最后一次尺寸变化后稳定 200ms 才结束，只通知状态切换。期间暂停装饰动画和 CSS 过渡；图表合并尺寸、数据更新，稳定后按最新数据绘制。后台采集继续。
- 刻度波纹使用相同更新边界，并隔离不变的波纹元素，减少尺寸变化期间的重复更新。卸载时清理监听、计时器、观察器及待执行绘制。
- 未新增设置、依赖、持久化字段或配置迁移；现有表单、页面及滚动状态继续保留。最大化失败沿用可见错误反馈。

## 原生对照与配置选择

环境：Windows 11 Pro 26300；WebView2 156.0.4314.50；AMD Radeon Graphics 驱动 31.0.12042.4，同时存在 OrayIddDriver 虚拟适配器；单显示器 3840×2160、60Hz、150% 缩放。

两组均取消 Mica、使用相同实色深色页面及上述优化，以真实 Tauri 窗口、相同桌面录屏参数测试。设置页与仪表盘各预热两次切换，再各执行 10 轮最大化和还原。测量阶段等待原生命令完成；每次视口在 2560×1392 与 1120×680 之间交替。

| 配置 | 页面 | rAF 间隔超过 50ms 次数 | rAF 间隔 P95 |
| --- | --- | ---: | ---: |
| A3：保留原生透明 | 设置页 | 32 | 50.0ms |
| A3：保留原生透明 | 仪表盘 | 34 | 83.2ms |
| B3：关闭原生透明 | 设置页 | 33 | 66.6ms |
| B3：关闭原生透明 | 仪表盘 | 33 | 399.3ms |

两组合计长间隔次数相同，但不透明方案没有表现出收益，且仪表盘 P95 更差。因此采用计划中的回退：保留原生透明，页面外观仍为实色。录屏保留系统窗口动画；以上 rAF 数据属于 WebView 回调间隔，不代表原生合成帧率，也不能证明卡顿已经消除。录屏本身有开销，结果只用于本机配置选择，不作通用性能结论。早期桌面背景、主题或等待方式不同的探索数据未纳入本表。

本机视频与原始数据位于 `%TEMP%\dockmapper-native-motion-results` 的 `A3`、`B3` 文件中。录屏可能含桌面内容，不纳入仓库。测试专用远程调试参数已移除，最终原生进程重新启动后 9228 端口不再监听。

## 行为证据与边界

- 真实原生窗口两组测试中，表单值和滚动状态保持，仪表盘保留两个图表实例。
- 在真实 WebView 中持续触发尺寸活动，同时让采集继续：调整期间图表没有执行 `setOption` 或 `resize`；稳定后恢复最新采样。后续正常采样仍继续更新，不能将其算作重复的稳定刷新。
- 离开仪表盘后旧图表实例已释放。快速切换主题后实色背景匹配最终主题，没有主题同步错误通知。
- 真实鼠标拖动窗口右下边缘成功，窗口缩小 160×80 物理像素。仅有一个显示器，跨不同缩放比例显示器未验证。
- 新增协调器回归用例覆盖连续调整合并、稳定后的最新数据单次刷新、同帧合并及卸载取消。遵循本任务命令边界，未额外执行 Vitest。Rust 增加背景权限仅属于主窗口的回归测试。
- 原生开发版交互已做上述验证；未取得对应安装版 CI 产物，未做安装版交互验证。录屏抽查不能代替逐帧伪影分析，不能据此宣称所有黑白条、残影和停顿均已消失。
