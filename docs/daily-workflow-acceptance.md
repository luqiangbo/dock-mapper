# 日常操作、历史浏览与更新反馈验收

> 历史交付记录：仪表盘、阈值提醒与温度／GPU 功能已调整，当前行为以 [精简仪表盘与本机运行日志验收](runtime-log-dashboard-acceptance.md) 为准。原采样脚本已移除，本文旧命令不适用于当前版本。

## 本轮入口与行为

- 仪表盘顶部直接提供“开始截图”“快速 OCR”“最近截图”。最近截图区显示最新三张缩略图，可点击原图或进入全部历史；首次空、读取中、读取失败和重试分别呈现，监听历史变化后刷新。
- 仪表盘详细运行状态默认折叠；映射读取失败、系统映射变化、运行统计读取失败或快捷键注册失败在顶部保持警告，点击可展开并滚动至详情。异常仅在读取成功后清除；隐藏主窗口时暂停周期性运行状态查询，恢复时刷新。
- 历史默认按本机日期分组，显示日期和张数。开始／结束日期均包含当天全部记录，可只设一端或清除日期；收藏筛选与日期筛选可组合。最新／最早排序同时控制日期组及组内时间，“当日收藏优先”保持日期从新到旧，再在同一天优先收藏。
- 日期、排序、收藏筛选和列数复用原有本机浏览偏好存储；旧偏好补上不限日期。非法或反向的持久化日期范围恢复默认；界面中反向范围提示修正且不保存。写入失败显示警告和重试，浏览仍可继续。PNG、manifest 和缩略图存储不变。
- 原图窗口提供上一张／下一张按钮及无修饰键的左右方向键；遵循打开时的筛选和展示顺序，首尾不循环。单张、空列表、输入区域、长按和组合键不会误触。切换会恢复适应窗口，旧读取和解码结果按捕获代次隔离，释放旧图片 URL；加载失败仍可重试或切换。切换操作失败保留当前图，显示原因及重试；目标已删除时可以从历史重新打开。
- 原图顺序仅属于本次预览会话，不持久化。历史页改变筛选不会悄悄改变已打开会话，重新打开图片时使用新顺序。首页最近截图的顺序为全部历史按时间从新到旧。
- 全局设置 → 软件更新：先检查，再由用户确认“下载并安装”。确认后弹窗关闭，在页内展示字节数和已知总大小时的百分比；未知大小显示等待状态，不伪造百分比。下载并校验完成后切换到启动安装程序，再显示可返回时的重启阶段。Windows 原生安装通常会直接退出应用，因此安装之后的页面状态可能不会出现，不代表已经验证安装结果。
- 检查、下载／校验、安装、重启失败各有原因和重试入口。下载／安装失败后重新检查并下载；若发现版本改变，重新等待用户确认。重启失败只重试重启。释放旧更新资源失败也会显示警告。
- 更新状态保留于主窗口的运行时模块，切换设置页再回来继续显示，不重复启动下载。完整退出应用后需重新检查，不做跨进程断点续传。新增更新阶段与资源释放权限，以及只允许原图窗口切换当前预览序列的命令；二进制图片 IPC 保持原样。

## 验证边界

- 前端补充状态测试：日期边界、旧偏好迁移、组合筛选、日期组内收藏排序；运行异常摘要；预览顺序与键盘保护；更新各阶段、已知／未知长度、离页后继续、失败重试、版本变化、迟到事件和资源释放失败。按照仓库规则不在本轮运行 Vitest，交由现有 CI。
- Rust 快速测试覆盖预览顺序与首尾、过期切换不能覆盖新打开截图，以及拆分更新权限和命令注册。模型测试保持跳过。
- 仅运行 `pnpm typecheck` 和 `src-tauri` 下的 `cargo test -- --skip model`；不运行全量构建、模型初始化或格式检查。
- 本轮静态检查 `pnpm typecheck` 通过；Rust 核心测试 155 项通过、0 失败，3 项模型相关测试过滤。新增前端行为测试未在本轮执行，不能据类型检查宣称行为测试已通过。
- 未做真实 Tauri 窗口交互验证，没有执行实际下载安装或重启。当前修改包含原生命令和权限，旧可执行文件及前端热更新不能证明新交互可用。

## 最短人工验收路径

1. 仪表盘：点击开始截图并取消，再点快速 OCR 并框选识别；完成截图后确认最近三张自动刷新、点击可预览。收起运行详情后模拟快捷键冲突，确认顶部仍显示原因且按钮能定位详情。检查浅深主题及 640px 窄窗口无横向溢出。
2. 历史：准备跨至少两个本机日期的记录 → 设置开始／结束日期 → 组合收藏筛选 → 检查日期组及数量 → 切页再返回确认偏好保留 → 清除日期恢复全部。检查无匹配记录和偏好保存失败重试。
3. 原图：在上述筛选结果中打开中间一张 → 左右方向键及按钮切换 → 确认顺序、首尾禁用、每张恢复适应比例 → 快速操作并从历史另开一张，旧结果不能覆盖 → F11／Escape 行为保持原有顺序。目标已删除或读取失败应显示错误并可重试／重新打开。
4. 更新：在受控更新源和候选程序中检查有更新及无更新 → 用户确认下载 → 查看百分比／未知长度 → 下载期间切页再返回 → 注入网络、签名或安装失败确认错误及重试。真实安装、退出和重启由受控候选版本单独验收，不通过修改真实发行版本或自动安装当前电脑上的更新制造证据。
