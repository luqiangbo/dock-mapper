# 运行时按键映射验收

本轮将“按键映射”改为进程内运行。主窗口最小化、隐藏到托盘时继续；托盘退出停止。规则及总开关保存到原子 JSON 配置，同一构建普通重启保留，新构建或重新安装按已有规则重置。截图历史及独立恢复资料保留。

## 实现链路

- 页面添加、编辑、启停、删除、清空规则 → 现有规则保存 IPC → 独立运行时规则校验 → 专用消息线程切换键盘钩子 → 原子保存；失败恢复之前的运行规则，前端保留已保存列表及编辑输入并提示错误。
- 总开关与托盘开关走同一事务。没有启用规则时不安装低级键盘钩子。Raw Input 展示模块继续只观察，不承担重映射。
- 回调跳过注入事件并标记本应用输入。按下时固定目标，跟踪目标持有数量；重复按键、多个源键共用目标、物理目标键和规则切换分别处理。暂停、换规则及正常退出先释放合成键；无法释放时保留重试记录并明确报错。
- 前台权限检查在专用消息线程执行，窗口变化事件加定时检查更新缓存；低级键盘回调只读取缓存并转发输入。未知或受限窗口先放行原始键，不进行链式映射。高权限窗口会提示限制；返回普通窗口后重新检查并释放待释放按键，仍失败可重试运行。日志只记录状态变化，不记录实际输入。
- 遗留区域直接读注册表，不根据应用的旧“已应用”标记推断。无法解析时保留异常提示；未知扫描码显示十六进制；读取失败阻止映射，不能显示为系统干净。
- 旧配置只迁移一次：先独立备份旧规则，清空旧规则并写入迁移版本。注册表读取异常会明确记录在恢复资料中，并由状态页阻止运行时启动；不会当作没有系统映射。
- 点击清理后先写 `keyboard-recovery/prepare-*.json`，再单独请求 UAC。管理员助手只接受 `clearLegacy` 动作，重新校验预览原始值，独立写入 `clear-*.json` 后再删除整个 Scancode Map。保存失败回滚注册表；UAC 取消或其他失败保留恢复资料并反馈原因。
- `clear-*.json` 同时保存系统启动时间。同一启动期间暂停运行时；重启且注册表为空后解除。恢复目录不随安装或构建偏好重置清空。旧的系统写入、恢复 IPC 已取消注册及主窗口授权。

## 自动化证据范围

仅执行 `pnpm typecheck`、`cargo test -- --skip model`。前端现有状态测试已同步命令类型与语义，但遵循仓库限制不执行前端测试套件。

Rust 状态测试包含：迁移只发生一次及备份原始规则；旧版本识别；未知扫描码和格式异常；备份失败禁止写注册表；预览变化及备份期间变化中止；保存失败回滚；清理重启阻塞及重启后解除；普通重启保留、新构建与安装重置并保留恢复资料；UAC 取消保留恢复资料；规则保存失败回滚；长按、左右修饰键扫描码、禁用目标、多源共享目标、暂停释放、换规则时旧抬键、暂停恢复、注入事件隔离、注入失败放行；命令契约及主窗口权限。

这些测试使用临时目录、内存输入事件和模拟注册表写入，不能证明原生 Windows 输入、UAC 或托盘真实交互可用。未实际清理本机注册表，未运行生产构建。

## 最短人工路径（未做真实交互验证）

1. 打开“按键映射”，确认当前系统源键和目标键可见，存在遗留项时状态为阻塞。点击“清空系统映射并重置旧规则”，先试一次取消 UAC，确认错误反馈及恢复文件仍在；再确认清理，看到等待重启提示。
2. 重启 Windows，确认原键盘恢复。添加 `F8 → B`，在记事本按 F8，确认输出 B。隐藏主窗口到托盘后重复，确认继续生效。
3. 托盘暂停，F8 不再输出 B；启用后恢复。编辑目标、关闭单条规则、删除及清空规则，确认即时生效。普通重启软件确认保存的规则和总开关仍在。
4. 两个源键映射同一修饰键，按住两个源键、分别抬起，确认最后一个抬起才释放目标。按住源键时修改规则、暂停和退出，检查没有卡键。另测在启用前已按住的物理目标键。
5. 切入管理员记事本，确认原始输入被放行并出现权限提示；返回普通窗口检查恢复。检查按住修饰键时退出，以及异常终止后没有持久系统映射。
6. 再次启动开发服务或新安装，确认应用规则回到默认，`keyboard-recovery` 及截图历史仍在，注册表没有被静默修改。

真实交互未执行：UAC 授权/取消、系统清理与重启、实际键盘注入、托盘运行、管理员窗口、按住键退出和异常终止。上述流程须在 Windows 11 x64 上人工确认，不能以类型检查或模拟测试替代。
