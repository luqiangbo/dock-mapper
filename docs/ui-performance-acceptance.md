# 全窗口界面与性能改动验收

## 已实现的入口与状态

- 配置中心：导航分组、设置置底、800px 以下图标导航、页面按需加载及加载失败重试；首次进入仪表盘，之后恢复上次页面和截图标签。外部导航事件优先于已恢复页面，切页回到内容顶部。
- 截图历史：标题与开始截图独立一行，筛选工具另起一行；卡片信息及操作常驻。首次加载、空历史、空筛选、读取失败和后台刷新分别呈现；列表、缩略图和原图失败可重试。
- 截图浮层：常用工具常驻，其他工具和识别操作进入更多菜单；保存、贴图、复制及取消固定，工具区域在窄屏内滚动。沿用原有捕获代次、撤销、输出恢复与 OCR 失败重试流程。
- 贴图：右键菜单按实际尺寸限制位置，过长菜单可滚动，Escape 关闭菜单；透明度立即预览，写入串行合并，失败回到最近成功值并提供重试。读取配置前禁用调整、拖动和缩放。
- 挂件和按键展示：统一顶部预览、下方分组设置，取消左右分栏；挂件指标采用设置行，支持手柄拖拽和上移/下移，取消拖动不写入。保留任务栏透明背景、固定数值槽位和已有特效配置。按键显示为空时停止刷新计时器，有内容时恢复淡出更新。
- 主题：Ant Design 使用可计算的实际颜色值，页面变量由同源调色板设置；浅色下表格、预览与状态提示不再保留固定深色底。独立预览、桌面挂件及锁键状态提示读取已有主题偏好并同步变化。
- 界面精简与配色：移除通用设置“管理员权限说明”、截图设置“截图交互”和按键映射“稳定性说明”常驻提示；真实错误与应用确认保留。默认强调色改为灰蓝色，普通图标和悬停使用中性底色；导航、主按钮、趋势曲线及截图工具栏共用主题色，浅深主题分别派生可读的强调文字颜色。通用设置提供“恢复默认”，既有自定义颜色不自动覆盖。
- 历史原图：点击缩略图进入单个独立无边框窗口，支持滚轮按指针缩放、拖动平移、适应窗口、原始大小、双击切换比例、F11 全屏及 Escape 先退全屏再关闭。提供加载失败重试；快速切图忽略旧读取结果，关闭和切图释放原图 URL。原生 Acrylic 失败记录诊断并使用半透明底色。
- 截图设置常用工具：紧凑图标列表支持显示勾选、手柄拖拽、Alt+左右方向键排序、顺序预览及恢复默认。未勾选的编辑工具仍在更多菜单，输出动作与 OCR/二维码入口不变；全部取消勾选时仍可打开更多。拖动取消不提交，保存失败沿用截图设置的错误与重试反馈。

## 数据与兼容性

- 新增 `dock-mapper:navigation` 本地偏好项，保存页面和截图标签；非法值回到仪表盘。保存失败有警告。
- 已有主题色、侧栏宽度、截图浏览偏好、挂件与按键配置继续使用原有保存机制；设置队列离页时继续完成写入并保留错误提示。
- 配置原子 JSON 事务、PNG 历史、manifest、缩略图和原始二进制 IPC 未更改。贴图透明度和锁定仍是当前贴图窗口的运行时状态。
- 指标顺序继续写入原有挂件配置；样式和隐藏电池配置随指标 kind 保留。预设为空和八组上限有说明，同名覆盖与删除均确认。预览缩放、平移、全屏和会话代次仅保存在运行时，重开后适应窗口。
- 界面改动没有新增依赖。执行期间工作区另有依赖版本变更，pnpm 命令按当时的清单自动同步了依赖；没有覆盖这些清单变更。

## 最短人工验收路径

常用工具最短路径：截图 → 截图设置 → 勾选圆形、取消矩形 → 拖动圆形到首位 → 等待保存 → 开始截图并确认工具顺序及更多菜单 → 关闭截图、重开设置读取 → 恢复默认。另用 Escape 取消拖动，使用 Alt+左右方向键排序；保存失败时重试。配置新增 `toolbar_tools`（工具 ID、显示状态及数组顺序），沿用原子 JSON 保存；旧配置默认恢复原有六个常驻工具。原生保存完成后通知截图浮层更新，过期启动读取不能覆盖更新后的工具配置。新增前端常用工具测试未执行，未做真实交互验证。

本轮没有调整依赖版本。当前 npm 核心 API 为 2.12.1，Rust tauri 为 2.11.5，启动时的版本不匹配仍是原生交互验收前置问题；类型检查和 Rust 单测不会验证 Tauri CLI 的版本一致性。新入口、命令和权限需由更新后的原生程序加载，前端热更新不能替代原生更新。

1. 打开配置中心，在浅色与深色下分别检查 640×600、1120×680 和最大化；确认无整个窗口的横向溢出、导航可达、标题栏可拖动。再在 Windows 100%、150%、200% 缩放下检查菜单及键盘焦点。
   在通用、截图设置和按键映射页检查三块常驻说明已移除；通用设置 → 主题色 → 恢复默认，检查导航、按钮、图表与截图工具栏配色。再选自定义颜色、切换浅深主题、重开主窗口和截图，确认颜色保留，窄窗口下颜色选择及恢复按钮自然换行。
   主窗口可见性改由 WebView 的 `visibilitychange` 与焦点事件刷新，不再调用 `window.is_visible`。更新前端后，检查启动、隐藏到托盘和恢复窗口时无权限报错，恢复后仪表盘展示最新采样；实际隐藏事件是否触发仍需真实窗口验证。
2. 进入截图设置，修改一项后立即切页再返回，确认自动保存；停留在截图设置后重开主窗口，确认恢复该标签。从托盘打开截图历史，确认外部入口覆盖上次页面。
3. 开始截图，使用矩形、箭头、文字和马赛克；检查复制按钮只有对号且无背景色。马赛克中切换“像素块／柔和模糊”，调整颗粒或强度再次绘制，确认旧图层不变；取消拖动、撤销/重做、删除，再分别复制、保存、贴图并在历史中查看原图。覆盖非整数选区、屏幕四边、重叠区域及 100%、150%、200% 缩放：方块保持规整，模糊无透明/暗边，预览、提交与导出的位置误差不超过一个原图像素。切换工具、调整选区或开始新截图后检查旧拖动不会提交。重开截图确认效果与各自强度恢复；保存失败时点击属性栏“重试”，不支持模糊时检查禁用说明并选择像素块。打开更多菜单检查其他工具及 OCR，确认边缘选区输出操作仍可使用。
4. 在历史页点击原图，在独立窗口中滚轮缩放、拖动图片、拖动标题区域、调整边缘尺寸、双击切换比例；F11 全屏后按两次 Escape，确认先退出全屏再关闭。再打开并快速切换另一张图，确认复用窗口、恢复适应比例且不出现旧图。检查桌面磨砂、读取/解码失败重试及缩略图重试；继续验收收藏、筛选、复制和连续贴图。
5. 在贴图右下角打开菜单，连续调整透明度，再切换锁定并按 Escape。确认最终透明度正确、锁定提示可见、菜单关闭后焦点可继续使用。模拟写入失败时确认恢复最近成功值且能够重试。
6. 在浅深主题间切换，确认表格、设置预览、实际挂件、锁键状态及原图窗口同步。拖动指标手柄排序，另用键盘操作上移/下移；用 Escape 取消拖动，检查电池隐藏时配置保留及最后一个启用指标保护。保存后快速切页、重开读取顺序；检查预设首次为空、八组上限、同名覆盖确认及保存失败重试。调整按键展示内容和样式，确认预览及原窗口同步。连续开始两次截图，确认上一轮 OCR 的结果不会出现在新截图中。

## 性能对比方法（待实测）

在同一机器、相同窗口尺寸与采样间隔，使用相同的 100 条历史和 1440 分钟趋势数据，对比改动前后的开发版本：

| 场景 | 观察指标 | 本次代码路径变化 |
| --- | --- | --- |
| 设置页停留、主窗口隐藏与恢复 | React 更新次数、采样连续性 | 采集与界面拆开，隐藏时停止发布界面快照，恢复时发布最新数据 |
| 同一分钟持续采样 | 归档扫描、数组分配、长期图表更新次数 | 私有归档更新尾部桶，按分钟复制并发布；长期图表不再跟随每条实时样本更新 |
| 浏览 100 张历史缩略图后离页 | 同时进行的缩略图 IPC 数量、旧结果落入界面的次数 | 请求上限为 4，取消队列中的请求，忽略已执行请求的过期结果 |
| 连续缩放窗口或拖动侧栏 | 图表 resize 与工具栏测量次数 | 按动画帧合并，尺寸未改变时跳过更新 |
| 按键展示清空后等待，再次输入 | 空闲计时器、淡出与再次显示 | 清空后停止 150ms 计时器，有内容时恢复 |

记录实际次数、内存和耗时后再判断收益；本文件中的行为描述不是性能测量结果。
