# 取色最近颜色与收藏验收

## 已实现入口与行为

- 取色选项工具栏维持统一 36 px 高度，只保留复制格式、最近最多 5 个 22 px 色块和始终可打开的收藏数量按钮；没有独立星标或横向历史滚动。
- 复制的新颜色置首、重复颜色前移，第 6 个淘汰。一级点击直接按当前格式复制；二级点击仅选中，不复制。
- 收藏 Popover 约 320 px 宽，依次展示最近颜色、HEX 搜索、收藏网格及统一操作区。正常宽度每行 8 色，网格最高 240 px，窄窗口减少列数；面板整体也受窗口高度限制。
- 二级选中色保留独立 HEX 色样及复制、收藏/取消收藏操作，搜索忽略大小写及开头井号。取消收藏不会清掉选中色，允许立即重新收藏；复制及收藏更新不关闭面板。
- 首次打开优先选最新最近色，其次首个收藏；关闭清理搜索、选择和反馈。零收藏仍能打开，有暂无收藏、无匹配、加载及失败重试状态。
- 剪贴板成功有局部提示，失败保留选择和重试操作；写入成功后才更新收藏，写入失败显示错误。复制成功但最近颜色保存失败会明确提示。
- 菜单打开时暂停取色 C、空格及方向键，网格方向键移动焦点和选择，Enter 激活控件。搜索框 Ctrl+C 保持文本复制，其余 Ctrl+C 复制整图，Esc 一次关闭截图；不改变锁点取色面板。

## 数据与异步边界

- Rust 使用集合规范化并按原顺序去重，最近限制 5 个，收藏取消数量限制。新收藏置首，重复收藏不重排。
- 沿用原 recent/favorites 数组、原子配置写入及现有 IPC；其他标注颜色选择器仍只预览前 5 个收藏。
- 普通重启保留；新构建、重新安装继续随设置重置，无法恢复此前已被截断的收藏。
- 收藏写入队列与读取代次互斥校验，旧读取不能覆盖新收藏；捕获代次变化会失效旧读取和旧操作反馈。已开始写入允许完成，新截图重新读取。面板实例按捕获代次隔离。
