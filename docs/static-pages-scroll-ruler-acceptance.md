# 页面静态加载与刻度滚动条验收

## 已实现行为

- 开发环境禁用 Rsbuild 按需编译。主窗口六个页面静态导入，移除页面懒加载及菜单预加载；截图编辑器仍独立懒加载。
- antd Tabs 延续稳定 key、首次访问挂载及 `destroyOnHidden={false}`。页面活跃状态、业务加载、后台刷新和原来的滚动位置记录继续使用。
- 页面错误边界保留局部重试并记录错误；模块工厂缺失和分块失败提供带 antd 确认的界面重载入口，不自动刷新。启动阶段继续由原有首帧反馈、初始化门禁和看门狗负责。
- 主内容区与顶栏恢复全宽，取消独立通道；右内边距 24 px，刻度靠右 2 px，20 px 操作区域叠放在留白中。隐藏原生纵向滚动条；antd Slider 实现从上到下 0–100% 的点击、拖动及键盘操作，Page Up/Down 按可见内容高度翻页。
- 静止时显示 4 px 短刻度与细指示线；滚动时以 CSS 遮罩点亮当前位置上下约 64 px 的刻度，停止 900 ms 后收敛。悬停、拖动或键盘聚焦时展开至 10 px，过渡 180 ms；百分比复用 antd Tooltip 跟随指示线并自动避让，不常驻、不接收鼠标操作，层级低于菜单和弹窗。
- 同一个滚动容器提供位置事实，scroll/resize 通知按帧合并；ResizeObserver 同时监听容器与页面内容。无溢出时隐藏控件并清理交互计时，页面切换与卸载清理状态；首次按帧读取的恢复位置不触发滚动动效。减少动画时禁用过渡，高对比度时恢复原生滚动条。
- 没有新增依赖、IPC 或持久化偏好。已保存的数据、重置规则均沿用现有行为。更新控制器改为状态变化回调，静态创建时不注册日志订阅或请求更新。

## 验证证据

- 静态检查：根目录 `pnpm typecheck` 通过。
- 已执行自动化测试：`src-tauri` 下 `cargo test -- --skip model` 通过，206 项通过，3 项模型测试被过滤，文档测试通过。Rust 测试不证明本轮前端交互可用。
- 新增前端测试：首次只挂载当前页面、页面错误独立重试、资源错误重载确认、滚动比例/边界/内容不足一屏、恢复位置后读取且不触发动效、尺寸变化、按帧合并及清理监听；更新控制器静态创建不启动任务。刻度交互测试覆盖 900 ms 收敛、持续滚动重新计时、悬停/拖动/聚焦保持展开、页面切换及无溢出清理计时。按仓库约定未执行前端测试套件。
- 真实交互：未做真实交互验证；未执行生产构建，未复现原间歇性模块工厂缺失错误。不能据此认定该错误已彻底消除。
- 已访问页面往返后的实际草稿与滚动位置保留、鼠标拖动、触控板、主题与 DPI 的组合行为仍需人工确认。

## 最短人工验收路径

1. 从托盘退出旧实例，重新运行 `pnpm tauri dev`，确认首帧和初始化反馈连续。按既有规则，开发服务重启会产生新的设置重置标识。
2. 依次访问六个页面，确认没有页面模块加载占位；在历史页设置筛选、分页并滚动，往返其他页面后检查状态和位置。业务数据首次读取仍允许显示必要加载反馈。
3. 在长设置页使用滚轮、触控板、刻度点击/拖动、方向键、Home/End 和 Page Up/Down；检查顶部 0%、底部 100%，并确认窗口缩放及面板展开后比例更新。
4. 检查右侧空白减少、正文控件不被刻度遮挡；滚动时局部高亮且停止后收敛，悬停/拖动/键盘聚焦时展开并显示跟随百分比。在不足一屏的页面检查刻度隐藏、宽度不跳动；检查明暗主题、不同 DPI、弹层、高对比度和减少动画设置。确认页面位置恢复不触发动效，内容从顶栏下方经过、窗口按钮不被遮挡。
5. 用开发调试器模拟页面渲染异常及模块异常，检查局部重试、错误日志、取消重载不会刷新、确认重载才刷新；其他页未保存内容在重载前明确告知可能丢失。
6. 打开截图窗口，确认基础框选、编辑器独立加载和窗口内部滚动未受主窗口刻度改动影响。
