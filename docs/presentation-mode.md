# 演示辅助

主窗口「演示辅助」和托盘均可启停演示模式。默认快捷键为 `Ctrl+Alt+P`，
鼠标定位为 `Ctrl+Alt+L`，可在设置中修改；冲突会显示原因，并保留原快捷键。

默认展示组合键、功能键、鼠标点击、跟随光圈及 CapsLock / NumLock 状态。
普通字符键、单独修饰键默认隐藏。左右键和中键点击效果分别为蓝、粉、紫色，
持续 600 毫秒；黄色定位动画持续 1 秒，锁定键提示持续 2 秒。

演示偏好通过现有 JSON 事务保存在本机；启用状态不持久化，重启后关闭。
普通按键配置独立保留，退出演示时恢复。截图期间暂停辅助效果，取消或输出后恢复。
保存失败保留原偏好；偏好保存成功但原生启用失败时，会明确提示并退出演示模式。
所有输入只生成即时展示事件，不写入输入历史、不上传、不拦截键鼠操作。

## 实现边界

- `raw_input` 是唯一的键鼠 Raw Input 注册入口，沿用按键运行时管理线程生命周期。
- `presentation` 管理偏好、会话代次、快捷键及每个显示器的鼠标效果窗口。
- 按键窗口和鼠标窗口先完成事件监听及就绪握手，再显示；鼠标移动至多每 17 毫秒采样一次。
- 鼠标事件用桌面物理像素，前端按各显示器原点和缩放换算为 DIP。
- 新增 IPC 具备显式窗口权限；贴图与截图的二进制 IPC 保持原有路径。

## 人工验收（未执行）

1. 首次进入设置，确认可加载；启用演示，默认字符键不显示，`Ctrl+Shift+S` 显示组合键。
2. 左、右、中键点击桌面应用，确认圆环颜色、消退时间和底层点击正常；窗口不抢焦点。
3. 移动鼠标跨越不同 DPI、负坐标显示器，检查光圈跟随；触发定位后动画约 1 秒消失。
4. 切换 CapsLock、NumLock，核对系统实际状态；进入模式时显示初始状态，约 2 秒消失。
5. 分别只开启键盘、只开启锁定键、只开启鼠标及关闭全部选项，确认运行状态与效果一致。
6. 截图、取消、复制、保存及快速 OCR，确认冻结画面不含辅助效果，结束后恢复；连续快速截图不应提前恢复。
7. 退出演示，确认普通按键设置恢复；重启后演示关闭、偏好仍在。
8. 使用已占用或重复快捷键，确认有反馈、原快捷键保留，托盘和设置页仍可使用。
9. 断开显示器或改变缩放，确认旧浮层消失、新浮层定位正确；启动异常时可见错误并可重试。
