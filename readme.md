# DockMapper

面向 Windows 11 的桌面效率工具：把系统信息、按键操作和截图标注放在一个轻量应用里。

> 仅支持 Windows 11 x64。

## 能做什么

### 看见系统状态

- 在 Windows 11 任务栏显示上传、下载、CPU、内存、电池和磁盘 I/O。
- 在仪表盘查看实时概览和最近 5 分钟的网络、资源趋势。
- 自由选择指标顺序、显示样式、采样间隔与网速单位。

### 更顺手地使用键盘

- 通过按键映射调整常用按键；应用映射后重新登录或重启 Windows 即可生效。
- 用透明的「按键文本」悬浮窗展示最近输入；可筛选按键类别、调整字号、缩放和透明度。

### 更快地完成截图

- 支持窗口识别、自由框选、高 DPI 与多显示器截图。
- 截图标注是一块有限白板：支持选择、矩形、椭圆、菱形、多点线、三类流程箭头、画笔、高亮、马赛克、文字、编号和对象橡皮擦。
- 支持多选、框选、单层分组、八向缩放、旋转、图层调整、会话内复制粘贴、元素吸附和箭头端点绑定；形状可双击添加随容器变换的文字。
- RoughJS 样式可分别设置实线/虚线/点线、无/纯色/排线/交叉排线填充、三档粗糙度、描边与填充色、线宽和透明度；各工具样式保存在本机。
- 支持离线 OCR、二维码识别、取色、复制、保存、贴图与本地截图历史。

## 常用快捷键

| 快捷键              | 操作                               |
| ------------------- | ---------------------------------- |
| `Ctrl+1`            | 打开冻结截图并框选                 |
| `Ctrl+2`            | 将最近一次已确认的选区截图贴到屏幕 |
| `Ctrl+3`            | 打开主窗口中的截图历史             |
| `Ctrl+Alt+P`        | 隐藏或显示最近创建的贴图           |
| `Ctrl+Shift+1`      | 快速 OCR：框选后立即识别并复制文本 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做标注                    |
| `Ctrl+A`            | 全选当前截图中的对象               |
| `Ctrl+C/V` / `Ctrl+D` | 复制粘贴 / 快速复制所选对象      |
| `Ctrl+G` / `Ctrl+Shift+G` | 分组 / 取消分组              |
| `Ctrl+]` / `Ctrl+[` | 上移 / 下移一层（加 `Shift` 置顶 / 置底） |
| `Delete` / `Backspace` | 删除所选对象                    |
| `R`                 | 重复上一次选区                     |
| `Enter`             | 完成截图并复制                     |
| `Esc`               | 结束编辑或手势 → 清除选择 → 返回选择工具 → 取消截图 |
| `Delete`            | 删除当前选中的文字或编号           |
| `C`                 | 取色时复制不带 `#` 的 HEX 值       |

## 本地优先

截图、OCR、二维码识别、图片编解码和配置均在本机完成。按键文本只展示过滤后的键名，不拦截输入、不记录原始扫描码，也不会上传数据。

## 开始开发

需要 Windows 11 x64、Node.js、pnpm、Rust stable/Cargo 和 WebView2 Runtime。

```powershell
pnpm install
pnpm tauri dev
```
